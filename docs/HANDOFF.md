## Tasks checkpoint handoff

Tasks는 **execution-disabled, history-only** surface로 전환되었다. 누적 range review(`e366ffe..63be2f1`)에서 Codex가 보고한 HIGH finding이 VALID했기 때문이다. `internal/roborev/task.go`의 safety 검사는 Dashboard process 자신의 global config만 읽었을 뿐, 실제 enqueue를 수행하는 daemon의 effective config identity/safety state를 증명하지 못한다.

Upstream v0.64.0 확인 사실: config path는 각 process 자신의 environment(`ROBOREV_DATA_DIR` 포함)에 따라 달라질 수 있고, daemon은 시작 시 결정된 config path를 사용하므로 daemon과 Dashboard가 같은 config를 본다는 machine-verifiable 보장이 없다. ## Repositories v3A safe display-name rename handoff (2026-08-23)

Repositories v3A adds only the exact v0.64.0 `repo rename <path-or-name> <new-name>` display-name mutation. It does not rename directories or Git roots and does not mutate Dashboard Registry, registration, selection, bootstrap, repository-switch, Stats, Insights, Tasks or Setup semantics. The optional rename service and separate `repositoryRename` capability leave the base review service source-compatible. There is no v0.64 daemon rename mutation API, so the configured binary runs a typed shell-free argv with empty CWD, 10-second timeout and 64 KiB stdout/stderr bounds. Human stdout and exit zero are not authoritative.

The browser path is only a preview selector. Preview and Confirm use fresh strict inventory, require one byte-exact stored `root_path`, bind the raw current display name, and reject another row whose display name equals the target path. The command always targets the inventory-returned root path, never a display name. New names are trimmed, valid UTF-8, nonempty, at most 128 Unicode code points, and reject control characters, unchanged names and leading `-`; Korean, Unicode, spaces and ordinary punctuation remain valid. Leading-dash rejection is the audited Dashboard policy, so the builder does not depend on Cobra positional-terminator behavior.
